# Cybersecurity Study Handbook

By Dr. Atul Tiwari
{: .byline }

Original study material for three tracks: ethical hacking (CEH), penetration testing (CPENT level) and offensive AI security (COASP). It is written for anyone: students, IT staff, clinicians, career-changers. Each chapter starts from plain language, marks what to memorise and what to understand, and ends with a one-page exam cheat sheet.

Nothing here is copied from any vendor's courseware. Each chapter is checked against the official syllabus for coverage, and against public standards and tool documentation for accuracy.
